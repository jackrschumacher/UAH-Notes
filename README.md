## Vault structure

This repo is an [Obsidian](https://obsidian.md) vault — open the repo root as the vault.

| Folder | Contents |
| --- | --- |
| `Notes/` | All notes. Former Logseq `a/b` namespaces are real subfolders. Start at [[Courses]]. |
| `Daily Notes/` | Daily notes, `YYYY-MM-DD` |
| `Attachments/` | Images and PDFs |
| `Templates/` | Note templates |
